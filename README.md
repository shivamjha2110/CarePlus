## ✨ Key Features

### 👨‍⚕️ For Patients (User)
- **Advanced Search:** Find doctors by speciality (General Physician, Dermatologist, etc.).
- **Smart Booking:** Book appointment slots with real-time availability.
- **Profile Management:** Manage health records and profile details.
- **My Appointments:** View upcoming and past appointments with status tracking.
- **AI Chatbot:** Integrated support bot for quick queries regarding booking and fees.
- **Responsive Design:** Optimized for Mobile, Tablet, and Desktop.

### 🏥 For Doctors
- **Doctor Dashboard:** View daily appointments and earnings.
- **Profile Controls:** Update availability, fees, and bio.
- **Appointment Management:** Accept or cancel patient bookings.

### 🛡️ For Administrators
- **Global Dashboard:** Overview of total doctors, appointments, and revenue.
- **Doctor Management:** Add, edit, or remove doctors from the system.
- **Appointment Oversight:** View all system-wide bookings.

## 🛠️ Tech Stack

### Frontend
- **Framework:** [React.js](https://reactjs.org/) (Vite)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Routing:** React Router DOM
- **State Management:** React Context API
- **Icons:** Custom SVGs
- **Notifications:** React Toastify

### Backend (In Progress)
- **Server:** Node.js & Express.js
- **Database:** MongoDB (Atlas)
- **Authentication:** JWT (JSON Web Tokens)
- **Image Storage:** Cloudinary
- **Payment Gateway:** Razorpay Integration

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### Prerequisites
- Node.js installed (v16 or higher)
- MongoDB Connection String (for backend)

### 1. Clone the Repository
```bash
git clone [https://github.com/shivamjha2110/CarePlus.git](https://github.com/shivamjha2110/CarePlus.git)
cd CarePlus
2. Frontend Setup
Navigate to the frontend folder.

Bash

cd frontend-folder-name # (Replace with your actual frontend folder name)
npm install
# or
yarn install
3. Environment Variables
Create a .env file in the root directory and add the following:

Code snippet

VITE_BACKEND_URL=http://localhost:4000
VITE_RAZORPAY_KEY_ID=your_razorpay_key
4. Run the Application
Bash

npm run dev
The app will open at http://localhost:5173.
